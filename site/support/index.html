安装与启动

提示「无法打开，因为无法验证开发者」

正式版已做 Developer ID 签名和 Apple 公证，正常不会出现此提示。如果出现，说明你下载的可能不是官网或 GitHub Releases 的原始文件，请重新下载。若确认来源无误，可在「系统设置 → 隐私与安全性」中点「仍要打开」。

提示「App 已损坏，无法打开」

这通常是下载过程被中断或被网络中间设备篡改导致的。请重新完整下载一次。使用自行构建版本（ad-hoc 签名）时也可能出现此提示，属于预期行为。

装完之后找不到窗口

Perch 没有 Dock 图标（LSUIElement），启动后常驻菜单栏。把鼠标移到屏幕顶部正中，或按 ⌘⇧V 唤出面板。

使用中的常见问题

复制了东西但没有上架

  • 检查面板头部的暂停按钮（⏸）是否处于暂停状态
  • 如果开启了「跳过被标记为机密的内容」，来自密码管理器的内容会被主动跳过
  • 与最新一条完全相同的内容不会新增，只会重置那一条的倒计时——这是预期行为

内容突然消失了

Perch 唯一的自动清理依据是保存时长，默认 12 小时。要长期保留某一条，双击该行固定它，固定的条目永不过期。另外剪贴板区最多保留 200 条，超出会丢弃最旧的（固定项不参与淘汰）。

拖不出去 / 拖到目标位置没反应

部分应用的拖放区域实现不标准，只接受特定类型。可以先试着拖到访达或桌面确认 Perch 侧正常，再判断是不是目标应用的问题。遇到具体应用拖不进去，欢迎提 Issue 告诉我们是哪个。

外接显示器上唤不出来

面板会出现在鼠标当前所在的那块屏幕上。如果刚接上显示器时异常，可以先移动一下鼠标；仍不正常请提 Issue 并附上显示器分辨率和排列方式。

卸载

把 Perch.app 拖到废纸篓即可。如需同时删除数据，再删掉这个目录：

~/Library/Application Support/Perch/

也可以在卸载前先用设置里的「抹掉全部数据」。Perch 不安装任何系统级组件、后台守护进程或内核扩展。
