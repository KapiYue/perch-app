## ⚠️ 使用前必读：隐私

**Perch 会记录你复制的一切内容，并保存到你的 Mac 本地磁盘。** 这包括你从密码管理器里复制的密码、验证码、身份证号等任何敏感信息。

**Perch 不会尝试识别哪些内容是敏感的。** 基于猜测的「智能过滤」会给你一种不可靠的安全感 —— 它一定会漏，而漏掉的那次恰恰最危险。所以我们选择把事实完整告诉你，把控制权交给你：

| 你的控制手段 | 位置 |
|---|---|
| 一键暂停监听 | 面板头部 **⏸** 按钮，常驻可见，状态跨重启保留 |
| 抹掉全部数据 | 设置页 |
| 跳过被标记为机密的内容 | 设置页，**默认关闭**，见下方说明 |

数据全部存在 `~/Library/Application Support/Perch/`，**一个字节都不上传**。没有账号、没有云同步、没有遥测、没有崩溃上报。App 运行期间不发起任何网络请求（Sparkle 更新检查除外，可关闭）。

> **关于「跳过被标记为机密的内容」**：macOS 上有一个社区约定，密码管理器等 App 会在剪贴板上打 `org.nspasteboard.ConcealedType` 标记。识别这个标记不是猜测内容，而是尊重来源 App 的显式声明。这个开关默认关闭，由你自己决定是否打开。

**如果你不接受这一点，请不要安装 Perch。**

完整政策见 [隐私政策](https://perch.joy-coder.com/privacy)。

## 权限说明

| | |
|---|---|
| **申请了什么** | 无。Perch 不需要任何需要你点「允许」的系统权限 |
| **不申请辅助功能**（Accessibility） | 不读取其它 App 的界面内容 |
| **不申请屏幕录制** | 不截屏、不录屏 |
| **不装全局鼠标钩子** | 所以也没有「抖一抖召唤」，见下方设计取舍 |
| **不读取** | 通讯录、日历、照片库、浏览器历史 |

App Sandbox **关闭**。这是为了让「把内容拖出去变成真文件」和任意路径访问能正常工作，代价是上不了 Mac App Store，只能自行分发 —— 这是已知并接受的取舍。

## 功能

### 剪贴板：复制即上架

后台每 0.5 秒检查系统剪贴板的变更计数，变了才读内容。类型按优先级判定：图片 → 文件 URL → 链接 → 纯文本。

- 文本、链接、图片自动分类，图片显示真实缩略图，链接绿色显示
- 前九条带 `⌘1`–`⌘9` 序号
- 最多保留 200 条，超出淘汰最旧的（固定项不参与淘汰）
- 复制的文件路径自动转入文件区，不占剪贴板的位置

### 四条取出路径

| 操作 | 结果 |
|---|---|
| **单击整行** | 内容复制回剪贴板 |
| **`⌘1`–`⌘9`** | 取第 N 条，手不离键盘（面板展开时生效）|
| **拖住往外拖** | 落地成真文件（文字 → `.txt`，截图 → `.png`） |
| **双击整行** | 切换固定状态，固定项永不过期 |

### 文件：临时中转架

- 从访达拖进来，切 Space、切 App，再拖到目标位置
- `⌘` / `Shift` 多选，`⌘A` 全选，选中后可批量：拖出 / 打包 ZIP / 固定 / 移除
- 空格键 Quick Look 预览，双击用默认 App 打开
- 右键：在访达中显示 / 复制路径 / 重命名 / 固定 / 移除 / AirDrop 分享
- **拖进来的文件会被拷贝一份**，之后你移动、重命名甚至删掉原文件，架上这份都还在

### 入口：屏幕顶部热区

入口定义是「屏幕中上方的一块热区」，**不是「物理刘海」**：

- **有刘海的机器**：热区贴着刘海渲染，视觉上像刘海的延伸
- **无刘海的机器**（外接屏 / iMac / Mac mini）：在屏幕顶部正中渲染一条同尺寸的黑色圆角条
- **多屏**：面板出现在鼠标当前所在的那块屏幕上

三种唤出方式：单击热区、悬停（鼠标移开 0.4 秒后自动收起）、全局快捷键。拖着文件悬停到热区上也会自动展开并接收放下。

面板展开时**前台 App 的输入光标不会消失** —— 你可以一边在编辑器里打字，一边唤出 Perch 取一条内容。

### 自动清理

- 保存时长可选 **1 小时 / 12 小时 / 24 小时 / 7 天 / 永不**，默认 **12 小时**
- 这是**唯一**的自动清理依据，没有其他隐藏的触发条件
- 固定的条目永不过期
- 重复复制同一内容不会新增条目，只重置那一条的倒计时

## 安装

### 直接下载

从 [官网](https://perch.joy-coder.com/#download) 下载 DMG。已用 Developer ID 签名并经 Apple 公证，双击不会报「已损坏」。国内节点直连。

海外用户或官网打不开时走 [GitHub Releases](https://github.com/KapiYue/perch-app/releases/latest)。

### Homebrew

```bash
brew tap kapiyue/tap
brew install --cask perch
```

### 自行构建

没有开发者账号也能构建可用版本，脚本使用 ad-hoc 签名：

```bash
git clone https://github.com/KapiYue/perch-app.git
cd perch-app
./script/build_unsigned.sh
```

**系统要求**：macOS 14 Sonoma 或更高，Apple Silicon / Intel 通用。

## 设计取舍

每一条都是讨论过、有理由的决定，不是还没做完。

- **不做抖动召唤手势。** 那个交互解决的是「手上正拖着东西、临时变出一个货架」，而 Perch 的用法是「先攒着，过一会儿再取」。砍掉它省去了全局鼠标钩子 —— 少一个误触发源、少一项权限、少一次被安全软件误报。
- **不做密码识别。** 理由见上方隐私说明。
- **不做云上传、公开链接、iCloud 同步。** 这是「不联网」能成立的前提。
- **不做文件标签、分类、搜索。** 那是文件管理器的活。架上的东西默认几小时后就没了，给临时内容建索引是本末倒置。
- **不做自动化脚本引擎。** 会把一个「抬手就用」的工具变成一个需要先配置的工具。
- **剪贴板用文本列表而非卡片，复制反馈只做行内，上下分区而非单一列表。** 都是返工一轮后确认的结论。
