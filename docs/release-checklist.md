# 第一部分 · 市场定位

## 一、市场上已有什么

macOS 上这个需求被切成了两半，两边各有成熟产品，但没有人把它们合起来。

### A. 文件暂存架

| 产品 | 授权 / 价格 | 做了什么 | 缺什么 |
|---|---|---|---|
| **NotchDrop** | 开源 MIT，免费 | 刘海位置的文件暂存架，拖入拖出 | **完全不管剪贴板**；强依赖物理刘海 |
| **Dropover** | 付费买断 | 抖动召唤临时货架，文件暂存，支持云上传生成分享链接 | **完全不管剪贴板**；依赖全局鼠标钩子 |
| **Yoink** | 付费（App Store / Setapp） | 屏幕边缘文件架，iOS 端联动 | **完全不管剪贴板**；沙盒限制部分场景 |

### B. 剪贴板管理器

| 产品 | 授权 / 价格 | 做了什么 | 缺什么 |
|---|---|---|---|
| **Maccy** | 开源 MIT，免费 | 纯剪贴板历史，快捷键唤出，极轻量 | **完全不管文件**；内容不能拖出成文件 |
| **Paste** | 订阅制 | 剪贴板管理做得最精致，iCloud 跨设备同步，Pinboard 分类 | **完全不管文件**；要联网要账号；订阅 |
| **PasteNow / CleanClip 等国产** | 买断或订阅 | 剪贴板历史，部分带图片管理 | 同上，文件线缺失 |

### C. Launcher 附带的能力

| 产品 | 说明 |
|---|---|
| **Raycast** | 内置 Clipboard History，免费档可用 |
| **Alfred** | Clipboard History + File Buffer，需买 Powerpack |

这两个都能覆盖一部分场景，但剪贴板历史是**藏在 Launcher 里的一个面板**，文件缓冲更是隐藏功能，两者不在同一个视图里，也没有常驻可见的货架。它们解决的是「搜索并调用」，不是「暂存并取回」。

## 二、Perch 的优点

按重要性排序，前两条是真正的护城河，后面是加分项。

1. **剪贴板 + 文件在同一个入口，且后台自动收集。**
   这是全表唯一没有第二家做的组合。上面所有产品要么只管文件、要么只管剪贴板。用户不需要先想起「我要打开某个工具」——复制即上架。

2. **剪贴板里的内容能拖出成真文件。**
   Maccy / Paste 只能粘贴回剪贴板；NotchDrop / Dropover / Yoink 只能拖动**本来就存在的**文件。Perch 用 `NSFilePromiseProvider`，在松手那一刻才生成文件，所以一段文字可以直接拖成 `.txt` 丢进邮件附件区，一张截图可以直接拖进上传框。**这是技术上最难、也最难被抄的一条。**

3. **入口不依赖物理刘海。**
   定义的是「屏幕中上方的一块热区」。外接显示器、iMac、Mac mini 上渲染一条同尺寸的虚拟黑条，体验完全一致。NotchDrop 在无刘海机器上就不成立。

4. **按时长自动清理，固定项豁免。**
   大多数竞品按条数淘汰（保留最近 N 条）。按时长更符合「临时中转」的心智：东西该过期就过期，重要的钉住。

5. **不联网、权限干净。**
   不申请辅助功能权限、不申请屏幕录制、不装全局鼠标钩子、不发任何网络请求。Paste 要账号和 iCloud，Dropover 的抖动召唤需要全局鼠标钩子。对剪贴板类工具来说，权限少本身就是卖点。

6. **免费、MIT 开源、可自行审计与构建。**
   剪贴板工具是信任生意，源码可读比任何隐私承诺都有说服力。

## 三、必须同时承认的短板

发布文案里不要回避这些。用户装上十分钟就会发现，不如自己先说。

- **上不了 Mac App Store。** App Sandbox 必须关闭，否则拖出功能残废。只能官网 / Homebrew 分发。
- **没有跨设备同步。** 不做 iCloud，Paste 的多设备场景 Perch 覆盖不了。
- **没有云分享链接。** Dropover 能生成链接分享，Perch 不做云上传。
- **不做密码识别。** 复制密码会照常上架。Paste 一类产品会尊重密码管理器标记并默认跳过，Perch 把这个开关交给用户且默认关闭。
- **仅 macOS 14+**，且不会有 Windows 版。
- **文件线的完成度低于专业文件架。** 不做标签、分类、搜索，也不打算卷这些。

## 四、一句话定位

> 别的工具让你二选一：管文件的不管剪贴板，管剪贴板的碰不了文件。
> Perch 把两条线合成屏幕顶部的一个入口，而且是自动的。

竞品的价格、授权方式和功能会变。**下列信息在每次大版本发布前重新核对一遍**，改完同步更新三处：本文、`README.md` 对比表、官网首页对比表。
