隐私政策

最后更新：2026 年 8 月 13 日 · 适用于 Perch（栖架）macOS 应用及本网站

⚠️ 请务必先读这一段

Perch 会记录你复制的一切内容，并保存到你的 Mac 本地磁盘。这包括你从密码管理器中复制的密码、验证码、身份证号等任何敏感信息。

Perch 不会尝试识别哪些内容是敏感的。我们认为，基于猜测的「智能过滤」会给你一种不可靠的安全感——它一定会漏，而漏掉的那次恰恰最危险。所以我们选择把事实完整告诉你，把控制权交给你。

如果你不接受这一点，请不要安装 Perch。

一、我们收集什么

准确地说，Perch 不「收集」任何数据——没有任何信息离开你的设备。下面列出的是 Perch 在你本机上保存的内容：

  • 你复制到系统剪贴板的文本、链接、图片
  • 你主动拖入 Perch 面板的文件（会被完整拷贝一份）
  • 上述条目的元数据：类型、大小、创建时间、是否固定
  • 你的应用设置：保存时长、全局快捷键、是否开机启动、监听是否暂停

Perch 不读取你的通讯录、日历、照片库、浏览记录、位置或任何其他系统数据。

二、数据保存在哪里

全部数据只存在于你的 Mac 上，路径为：

~/Library/Application Support/Perch/ ├── index.json 条目元数据（只存路径，不存内容本体） └── blobs/<uuid>/ ├── content.* 图片 / 文件本体 └── thumb.jpg 缩略图

这个目录随你的用户账户存在。如果你开启了 Time Machine 或 iCloud 云盘备份整个用户目录，该目录可能会被你自己的备份方案一并备份——这是你的备份设置决定的，不是 Perch 的行为。

三、我们不做什么

  • 不上传。Perch 不会把你的任何内容发送到我们或第三方的服务器
  • 没有账号系统。不需要注册、不需要登录
  • 没有云同步。不使用 iCloud、不提供跨设备同步
  • 没有遥测和统计。不采集使用行为、不上报崩溃日志、不集成任何分析 SDK
  • 没有广告。应用内不含任何广告或广告 SDK
  • 不做密码识别。见页首说明

四、唯一的网络请求：检查更新

Perch 使用 Sparkle 进行自动更新。检查更新时，Perch 会向我们的更新源请求一个版本描述文件。该请求会不可避免地让服务器看到你的 IP 地址、操作系统版本和当前 Perch 版本号——这是 HTTP 请求的固有属性，我们不会记录、关联或分析这些信息。

你可以在设置中关闭自动检查更新。关闭后 Perch 不会发起任何网络请求。

五、你的控制权

  • 随时暂停监听。面板头部有常驻可见的暂停按钮（⏸），点一下立即停止记录剪贴板，状态跨重启保留
  • 自动过期。默认 12 小时后自动清理，可改为 1 小时 / 24 小时 / 7 天 / 永不。清理时会同步删除磁盘上的文件
  • 单条移除。每一条都可以随时单独删除
  • 抹掉全部数据。设置中提供一键清空，会删除上述整个目录
  • 跳过机密内容（可选，默认关闭）。部分密码管理器会在剪贴板上打 org.nspasteboard.ConcealedType 标记。开启此项后 Perch 会跳过带此标记的内容。这是尊重来源应用的显式声明，不是我们去猜测内容，因此可靠性取决于来源应用是否规范打标
  • 直接删除数据目录。你也可以在访达中直接删掉上面那个目录

六、权限

Perch 不申请以下权限：

  • 辅助功能（Accessibility）
  • 屏幕录制
  • 完全磁盘访问
  • 通讯录、日历、照片、位置、麦克风、摄像头

Perch 也不安装全局鼠标钩子或输入监听。剪贴板读取使用的是 macOS 公开的 NSPasteboard 接口，该接口在 macOS 上不需要用户授权——这也正是我们必须把记录行为写在最显眼位置的原因。

Perch 关闭了 App Sandbox，因为沙盒会导致「把内容拖出成真文件」失效。这意味着 Perch 在技术上具备访问你文件系统的能力。我们的承诺是它只读写自己的数据目录和你主动拖入的文件；你可以通过审阅源码来验证这一点，代码完全开源。

七、本网站

本网站（perch.joy-coder.com）是纯静态页面，不设置任何 Cookie，不使用统计或分析服务，不含第三方追踪脚本。服务器会产生常规的访问日志（IP、时间、请求路径、User-Agent），仅用于安全排查，不用于用户画像。

软件安装包托管于腾讯云对象存储，下载时该服务会按其自身规则记录访问日志。

八、儿童

Perch 是通用生产力工具，不面向 14 周岁以下儿童设计，也不会主动收集任何年龄信息。

九、变更

本政策如有修改，会更新本页顶部的日期，重大变更会在应用更新说明中一并告知。历史版本可在 GitHub 仓库的提交记录中查阅。

十、联系

隐私相关问题请通过 支持页面联系，或直接在 GitHub 提 Issue。
